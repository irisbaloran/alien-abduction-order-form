# Alien Abduction Order Form

This is my first project built through the Master.dev bootcamp using HTML and CSS.

The original project was based on the form exercise from:
https://master.dev/bootcamp/html-forms/

While following the project requirements, I decided to redesign the original interface because I felt the provided form looked a little outdated. I kept the core form structure and functionality, but created my own visual direction with a more modern, playful alien-themed UI.

This project helped me practice building forms, using semantic HTML, styling layouts with Flexbox, and improving an existing design with my own CSS.

## Features

- Contact information section
- Alien abduction preference section
- Radio buttons
- Select dropdown
- Textarea
- Checkbox
- Submit button
- Side-by-side form and image layout
- Custom alien-themed visual design
- Rounded borders and offset box-shadow styling
- Responsive sizing with Flexbox

## Built With

- HTML5
- CSS3

## What I Practiced

While building this project, I practiced:

- Creating accessible form labels
- Using `fieldset` and `legend`
- Working with different input types
- Using Flexbox for layouts
- Using `box-sizing: border-box`
- Styling borders and rounded corners
- Creating a thick offset shadow with `box-shadow`
- Using `object-fit: cover` for images
- Organizing CSS with classes

## Future Improvements
Some features I may add later:
- Responsive mobile layout
- Form validation
- Multi-step form using JavaScript
- Animations and hover effects
- Better accessibility and keyboard support

## Design Changes

The original bootcamp version focused mainly on the structure of the form.

For my version, I redesigned the UI to make it feel more modern and visually engaging. I changed the layout, added a custom illustration, used a side-by-side design, introduced a stronger color palette, and added rounded borders and a bold box-shadow effect.
